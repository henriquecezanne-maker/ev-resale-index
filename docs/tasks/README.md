# Task groups

This folder stays **empty** for small projects — their task list lives directly in
[`docs/roadmap.md`](../roadmap.md) (the "Status checklist" section).

For **larger projects**, the `/split-into-tasks` command creates numbered task-group
files here:

```
01-setup.md
02-core.md
03-polish.md
...
```

Each file is sized so it can be completed in roughly **one working session** and
contains a short goal statement plus a checkbox task list. Work through the files in
order and check items off as they are completed.
